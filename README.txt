REVISION HUB — YEAR 13

This version automatically creates a flexible daily checklist for Biology, Chemistry and Maths.

The checklist is generated from weekly targets, completed work, missed work, topic status and exam deadlines. It does not assign fixed revision times.

Default weekly targets:
- Biology: 4.5 hours homework + 1 hour exam questions
- Chemistry: 4.5 hours homework + 1 hour exam questions
- Maths: 4.5 hours homework + 1 hour exam questions
- Anki: about 60 minutes total Monday-Saturday, shared between Biology and Chemistry; no Anki is generated on Sunday

Each generated non-Anki task is assigned a specific topic to revise. The app starts with a broad common A-level topic bank; update the Topics section to match your exact exam board.

Data is stored locally in the browser. Use Backup in More to export your data regularly. Restore is available for JSON backups made by Revision Hub.

Direct live Anki deck synchronisation is not available to a normal browser-only app. The app therefore uses generated Anki tasks and manual session logging without pretending to have live card sync.

PWA: host the folder over HTTPS, open it in Safari on iPhone, then Share → Add to Home Screen.
